# 📌 UI/UX Bootcamp - Tugas: Landing Page & Login Page Design

Pada tugas ini, peserta diminta untuk membuat **design landing page dan login page** dengan tema bebas menggunakan **Figma**.

---

## 📖 Overview

Buatlah design untuk website dengan tema bebas dengan ketentuan berikut:

- **Landing Page** untuk convincing user untuk sign up
  - Sections: Header (navbar), Hero, Features (3-4), Footer
  - Professional & clean design

- **Login Page** untuk existing users
  - Form field: email, password
  - Remember me & forgot password options

---

## 📋 Ketentuan

1. **Research** — Cari ide untuk tema dan refrensi (bisa menggunakan dribble)
2. **Wireframe** — Buat low-fidelity wireframe untuk landing & login page
3. **Visual Design** — Design high-fidelity dengan:
   - Color palette (max 5 warna)
   - Typography system
   - Component library (buttons, cards, inputs)
   - 8px base grid
4. **Prototype** — Add interactions (min 5):
   - Button clicks → navigate
   - Form focus/error states
   - Hover effects
   
---

## 💡 Catatan

- Peserta diperbolehkan menambahkan sections atau features apabila dianggap diperlukan, selama tetap sesuai dengan landing page concept.
- Pastikan design konsisten (spacing, colors, typography) di semua pages.
- Gunakan **8px grid system** & follow design principles.
