# Academy Frontend - Tugas 2: Frontend

Selamat datang di penugasan frontend pertama untuk para calon frontend!

Untuk penugasan kalian, kalian akan diminta untuk membuat **Webpage** dengan
**framework frontend** bebas sesuai preferensi kalian!

Berikut adalah contoh framework yang bisa dipakai:
- React + React Router
- NextJS
- VueJS
- Svelte
- htmx
- dan lain-lain...

Untuk ketentuannya adalah sebagai berikut:

- [ ] Melakukan separasi antar-komponen, seperti sidebar, button, dll
- [ ] Memuat icon svg yang diinstall melalui `npm` atau `bun` (Bebas memakai icon apa, seperti lucide atau material)
- [ ] Memuat 3 laman utama, yakni: landing page, login/register page, dan user page ketika sudah login (boleh dummy terlebih dahulu)
- [ ] Routing antar laman

Bonus:
- [ ] Authentikasi dan routing yang telah terintegrasi dengan authentikasi
- [ ] Dapat menampilkan data melewati API (sama seperti kemarin, tetapi menggunakan keyword pada framework yang dipilih)
- [ ] Background pada landing page memiliki efek keren seperti segitiga floating.
