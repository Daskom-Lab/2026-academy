# Academy Frontend - Tugas 1: Frontend

Selamat datang di penugasan frontend pertama untuk para calon frontend!

Untuk penugasan kalian, kalian akan diminta untuk membuat **Webpage** hasil dari
desain UI dan UX yang telah kalian buat di penugasan sebelumnya!

- [ ] Memuat file html, css, dan js
- [ ] Memiliki komponen html: `header`, `main`, `footer`, `section`, dan lain-lain
- [ ] Memuat navigasi `nav` (bisa berupa sidebar maupun headerbar), yang bisa merujuk ke section/link yang lain
- [ ] Memuat konten hero (first impression ketika user pertama kali memasuki website)
- [ ] Responsif terhadap banyak ukuran window (minimal mode Handphone dan Komputer)
- [ ] Menggunakan vite untuk manajemen frontend

Bonus:
- [ ] Bisa menampilkan dan menyajikan data dari url berikut: [https://api.ptrkr.moe](https://api.ptrkr.moe).
- [ ] Memiliki/menambahkan konten dinamis, seperti counter atau todo-list.
- [ ] Komponen seperti button dan sidebar dipisah dalam file berbeda dengan file utama html.
- [ ] Manajemen proyek menggunakan github (cukup `git add` dan `git commit` saja).
