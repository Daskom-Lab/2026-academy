# Academy Backend - Tugas 2: Frontend

Selamat datang di penugasan frontend pertama untuk para calon backend!

Untuk penugasan kalian, kalian akan diminta untuk mengkonversi **Landing Page**
yang sudah kalian buat di Tugas 1 ke **Frontend Framework (Bebas)**

Contoh:
- React + React Router (Direkomendasikan)
- VueJS
- Svelte
- dll...
Boleh menggunakan Javascript atau Typescript

Berikut adalah kriteria yang harus dikerjakan:

- [ ] Memisahkan komponen web (seperti button, header, dll) ke komponen file tersendiri
- [ ] Dapat menampilkan data API dari luar (ataupun dari dalam) dan melakukan CRUD. Contoh: api.ptrkr.moe
- [ ] Membuat page lain minimal 2 (selain Landing Page) yang bisa diakses oleh antar-Page. Contoh: Login Page, User Page
- [ ] Menggunakan tailwindcss

Bonus:
- [ ] Teks dokumentasi Markdown apa yang kalian kerjakan (misal: cara pemanggilan komponen)
- [ ] Sekalian sama backend tipis2 lebih bagus...
